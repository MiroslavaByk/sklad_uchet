# Склад-Учёт 
 
Информационная система складского учёта (Python + 1С:Управление торговлей). 
Учебная практика, Быкова М.М., группа ИС-305 
 
## Функциональность 
- Управление справочником товаров 
- Приход и расход товаров 
- Автоматический расчёт остатков 
- Отчёты о движении товаров 
 
## Технологии 
- Python 3.10+ 
- Flask/FastAPI 
- 1С:Управление торговлей 8.5 
- XML-обмен данными
